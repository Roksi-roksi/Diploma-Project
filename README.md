# Дипломная работа: Автоматизация тестирования YouGile

Реализован проект автоматизации тестирования для платформы управления проектами **YouGile**. Проект включает в себя два независимых слоя: API-тесты и UI-тесты. Все автотесты спроектированы как **полностью независимые**, содержат аннотации типов, поддерживают стандарты PEP8 и используют явные ожидания Selenium (без `time.sleep()`).

## 📁 Структура проекта
* `api_tests/` — независимые API автотесты (тестирование CRUD, лимитов и валидации схем).
* `ui_tests/` — UI автотесты на базе паттерна Page Object (`pages.py`, `test_ui.py`).
* `conftest.py` — глобальный конфигурационный файл Pytest с хуками для Allure-скриншотов.
* `config.py` — конфигурационный файл с токенами и учетными данными.
* `pytest.ini` — файл внутренней конфигурации тестового фреймворка Pytest.
* `run_tests.ps1` — автоматизированный PowerShell-скрипт для очистки, запуска тестов и сохранения истории отчетов Allure.
* `requirements.txt` — список строго используемых внешних зависимостей.

## 🛠️ Установка зависимостей

1. Перейдите в корневую директорию проекта:
```bash
cd PythonProject4
```

2. Убедитесь, что ваше виртуальное окружение `.venv` активировано (в терминале должна быть отметка `(.venv)`). Если нет, активируйте его:
```powershell
.venv\Scripts\Activate.ps1
```

3. Установите строго используемые в проекте зависимости:
```bash
pip install -r requirements.txt
```

## 🧪 Инструкция по запуску тестов и генерации отчетов

В проекте настроено **автоматическое сохранение истории предыдущих запусков** для построения графиков стабильности (Trends). Запуск всей цепочки процессов автоматизирован через скрипт.

### Полный запуск проекта (Очистка + Тесты + История + Открытие отчета):
Для запуска всех тестов и автоматического открытия интерактивного HTML-отчета Allure в браузере выполните в терминале команду:
```powershell
./run_tests.ps1
```

### Локальный запуск отдельных слоев (без сборки Allure-истории):
* **Запуск только API-тестов:**
  ```bash
  pytest api_tests/test_api.py -v
  ```
* **Запуск только UI-тестов:**
  ```bash
  pytest ui_tests/test_ui.py -v
  ```
